# Política de Privacidad / Privacy Policy — Letraverse

**Última actualización / Last updated: 10 de agosto de 2026 / August 10, 2026**

## Español

### Resumen
Letraverse **no recolecta, almacena en servidores externos, ni comparte ningún dato personal**. Todo tu progreso, estadísticas y preferencias se guardan únicamente en tu propio dispositivo.

### Qué datos maneja la app y dónde viven
| Dato | Dónde se guarda | ¿Sale del dispositivo? |
|---|---|---|
| Progreso de niveles y mundos | Almacenamiento local (Hive) | No |
| Estadísticas (palabras encontradas, racha, tiempo jugado) | Almacenamiento local (Hive) | No |
| Preferencias (idioma, tema) | Almacenamiento local (SharedPreferences) | No |

Letraverse no requiere cuenta de usuario, no pide correo, nombre, ubicación ni ningún dato de identificación personal.

### Conexiones a internet
La app hace **solo dos tipos de solicitud de red**, ambas hacia la API pública de GitHub, y ninguna envía datos tuyos:
1. **Chequeo de actualizaciones**: consulta `api.github.com/repos/pedroespinal/letraverse/releases/latest` para saber si hay una versión nueva. No se envía ningún identificador tuyo — es una solicitud anónima de solo lectura.
2. **Descarga de actualización (Android)**: si eliges instalar una actualización, se descarga el archivo APK directamente desde GitHub Releases.

Ninguna otra función de la app usa internet. No hay analítica, no hay publicidad, no hay rastreo de terceros.

### Permisos que pide la app
- **Internet**: para el chequeo de actualizaciones descrito arriba.
- **Instalar apps desconocidas (Android, solo si usas la actualización in-app)**: necesario para que el sistema te deje instalar el APK descargado; Android te pedirá confirmarlo explícitamente cada vez.

### Menores de edad
Letraverse no está dirigida específicamente a menores, pero no recolecta ningún dato de ningún usuario, sin importar su edad.

### Cambios a esta política
Si esta política cambia, se actualizará la fecha al inicio de este documento y el archivo quedará disponible en el repositorio público del proyecto.

### Contacto
Pedro Espinal — a través del repositorio: https://github.com/pedroespinal/letraverse

## English

### Summary
Letraverse **does not collect, store on external servers, or share any personal data**. All your progress, stats, and preferences are saved only on your own device.

### What data the app handles and where it lives
| Data | Where it's stored | Does it leave the device? |
|---|---|---|
| Level/world progress | Local storage (Hive) | No |
| Stats (words found, streak, time played) | Local storage (Hive) | No |
| Preferences (language, theme) | Local storage (SharedPreferences) | No |

Letraverse requires no user account and asks for no email, name, location, or any personally identifying information.

### Network connections
The app makes **only two kinds of network request**, both to GitHub's public API, neither of which sends any data about you:
1. **Update check**: queries `api.github.com/repos/pedroespinal/letraverse/releases/latest` to see if a newer version exists. No identifier of yours is sent — it's an anonymous, read-only request.
2. **Update download (Android)**: if you choose to install an update, the APK file is downloaded directly from GitHub Releases.

No other feature in the app uses the internet. There is no analytics, no advertising, no third-party tracking.

### Permissions the app requests
- **Internet**: for the update check described above.
- **Install unknown apps (Android, only if you use the in-app update)**: required so the system lets you install the downloaded APK; Android will explicitly ask you to confirm this each time.

### Children
Letraverse is not specifically directed at children, but it collects no data from any user regardless of age.

### Changes to this policy
If this policy changes, the date at the top of this document will be updated, and the file will remain available in the project's public repository.
